# Daddu Charger Gaming Store: Concept Website

A premium redesign concept for **Daddu Charger Gaming Store** (Royal Plaza, Satellite Town, Rawalpindi).

**Live demo:** https://aziz4rehman-hue.github.io/Daddu-Charger-Dem0/

## Features
- Animated hero with a neon grid, particles and a 3D-tilting RGB gaming PC
- Product grid with the store's real PC builds and prices, plus a cart
- Live PC Builder: pick CPU, GPU, RAM, storage and case, see the price and estimated FPS, and send the build on WhatsApp
- Cart checkout on WhatsApp, sale countdown, reviews slider and store location
- Fully responsive, a single HTML file with no build step
